# LUX.D1.Legendre
[English](README.md) | [日本語](ja/README.md)

`LUX.D1.Legendre` evaluates orthonormal Legendre polynomials and their first derivatives, taking the argument either as $x$ (`NLegendre`, `dNLegendre`) or as the polar angle $\theta$ with $x = \cos\theta$ (`NLegendreCos`, `dNLegendreCos`). `LUX.D1.Legendre.Diff` overloads the same four functions for the dual numbers `TdSingle` / `TdDouble`.

## 1. Overview

Every function takes the degree `N_` as an `Integer` and is overloaded for `Single` and `Double`. Evaluation is by a finite cosine series whose coefficients are generated by a descending recurrence, which keeps intermediate values bounded and avoids the overflow of the naive factorial formulas even at high degree. `NLegendre` / `dNLegendre` simply convert through `ArcCos`, so their argument must satisfy $|x| \le 1$; the derivative form has the usual $1/\sqrt{1-x^2}$ singularity at $x = \pm 1$.

## 2. Mathematical Background

### 2.1 Orthonormal Legendre polynomials

The Legendre polynomial of degree $n$ is given by Rodrigues' formula [1]

```math
P_n(x) = \frac{1}{2^n n!} \, \frac{d^n}{dx^n} \left( x^2 - 1 \right)^n \qquad \text{(2.1)}
```

The unit returns the orthonormal rescaling $\tilde P_n$ (the leading `N` of the function names),

```math
\tilde P_n(x) = \sqrt{\frac{2n+1}{2}} \; P_n(x), \qquad \int_{-1}^{1} \tilde P_n(x) \, \tilde P_m(x) \, dx = \delta_{nm} \qquad \text{(2.2)}
```

so that, for example, `NLegendre( X, 0 )` $= 1/\sqrt{2}$ for every `X`.

### 2.2 Cosine-series evaluation

With $x = \cos\theta$, $\tilde P_n(\cos\theta)$ is a finite cosine series over the harmonics $k = n, n-2, \dots$ of the same parity as $n$:

```math
\tilde P_n(\cos\theta) = {\sum_{k}}' \, A^{(n)}_{k} \cos k\theta, \qquad k = n,\, n-2,\, \dots \qquad \text{(2.3)}
```

where the prime means that the $k = 0$ term (present for even $n$) enters with weight $\tfrac{1}{2}$. The code first forms the leading coefficient

```math
A^{(n)}_{n} = \sqrt{2} \, \prod_{m=1}^{n} \frac{\sqrt{(2m-1)(2m+1)}}{2m} \qquad \text{(2.4)}
```

(nested function `FNN` / `ANN`) and then descends through the harmonics two at a time (`FN20` / `AN20`):

```math
A^{(n)}_{k} = \frac{(n-k-1)(n+k+2)}{(n-k)(n+k+1)} \; A^{(n)}_{k+2} \qquad \text{(2.5)}
```

Both (2.4) and (2.5) multiply ratios that stay of order one, which is what makes the evaluation stable where the closed factorial form of the coefficients would overflow.

### 2.3 Derivatives

`dNLegendreCos` differentiates (2.3) term by term with respect to $\theta$:

```math
\frac{d}{d\theta} \, \tilde P_n(\cos\theta) = - {\sum_{k}}' \, k \, A^{(n)}_{k} \sin k\theta \qquad \text{(2.6)}
```

and `dNLegendre` applies the chain rule through $\theta = \arccos x$:

```math
\frac{d}{dx} \, \tilde P_n(x) = - \frac{1}{\sqrt{1-x^2}} \, \left. \frac{d}{d\theta} \, \tilde P_n(\cos\theta) \right|_{\theta = \arccos x} \qquad \text{(2.7)}
```

The `.Diff` overloads run the same series on dual numbers, so a seed derivative in the argument is propagated exactly through the whole evaluation.

## 3. Architecture

```
[ LUX.D1.Legendre ( + .Diff ) ]

・NLegendre( X, N )     ･･･ P̃_N(X),  requires |X| ≤ 1
・NLegendreCos( T, N )  ･･･ P̃_N(cos T)
・dNLegendre( X, N )    ･･･ d P̃_N / dX,  singular at X = ±1
・dNLegendreCos( T, N ) ･･･ d P̃_N(cos T) / dT
```

Each name is overloaded for `Single` and `Double`; the `.Diff` unit overloads the same names for `TdSingle` and `TdDouble` from `LUX.D1.Diff`.

```
・Legendre/
  ┣・LUX.D1.Legendre.pas      ･･･ orthonormal Legendre functions + derivatives
  ┗・LUX.D1.Legendre.DIff.pas ･･･ dual-number version
```

## 4. Usage

```pascal
uses LUX.D1.Legendre;

var
   X, T, P, D :Double;
begin
     X := 0.3;

     P := NLegendre( X, 5 );          // P̃₅(0.3)
     D := dNLegendre( X, 5 );         // d P̃₅/dx at x = 0.3

     T := Pi / 3;
     P := NLegendreCos( T, 5 );       // P̃₅(cos 60°), no ArcCos round trip
end;
```
